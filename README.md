# SEDA Project
*Design and Control of an Aerial Manipulator with Series Elastic-Damper Actuators for Aerial Physical Interaction*

## 🔹 Overview
An aerial manipulator with **Series Elastic-Damper Actuators (SEDAs)** for compliant Aerial Physical Interaction (APhI).

SEDA provides passive compliance through a parallel spring-damper mechanism.
