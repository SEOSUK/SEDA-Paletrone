# SEDA Project
*Design and Control of an Aerial Manipulator with Series Elastic-Damper Actuators for Aerial Physical Interaction*

## 🔹 Overview
This project focuses on the **design, implementation, and experimental validation** of an aerial manipulator equipped with **Series Elastic-Damper Actuators (SEDAs)** for safe and compliant **Aerial Physical Interaction (APhI)**.

The SEDA integrates a **mechanical spring and damper in parallel**, providing passive compliance and damping between the actuator and manipulator link.
